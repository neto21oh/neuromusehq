IMPORTANT: PHONE INSTALLATION REQUIRES A WEBSITE

Opening index.html directly from a ZIP or local folder lets you test most features,
but a phone cannot install the PWA from a file:// address.

For a real phone shortcut and offline app behavior, upload this entire folder to
an HTTPS website, for example:

https://neuromusehq.com/field-commander/

Then Ernest opens that link and installs it.

IPHONE

1. Open the link in Safari.
2. Tap the Share button.
3. Tap Add to Home Screen.
4. Tap Add.

ANDROID

1. Open the link in Chrome.
2. Tap Install ELARA inside the app, or open Chrome's menu.
3. Tap Install app / Add to Home screen.

DATA

Current beta data is stored locally on the device/browser.
Use Save / Backup regularly during beta testing.
